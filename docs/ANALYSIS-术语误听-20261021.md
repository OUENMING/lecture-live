## 3. 为什么现有的三道防线都没拦住

| 防线 | 本该抓什么 | 实际为什么没抓 |
|---|---|---|
| **数字三道核**（代数自洽 / 对照课件 / 标未核对） | 数字与公式 | **只核数字**。「体积质量」「RLM」不是数字 —— `M=MRT/PV` 那个记号错也在「公式」里，但它没被代数自洽抓到（因为形似） |
| **术语库**（本课新加入 8 / 15 条） | 术语一致性 | 术语库是**从转录里学的**，学到的是**写对的那几处**（`molar mass`）；学到的**正确形式**没有回头去**纠正**转录里的**错误变体** |
| **翻译**（`X-ClassLive-Tz` 无关，这里是术语注入） | 术语译名 | 翻译是**忠实**的：`volume mass` → 「体积质量」没错，**错在 EN**。术语注入表（`glossary/<课号>.txt`）只在 EN 出现 `molar mass` 时才生效 |
| **guards**（`repaired 1, dropped 1, flagged 1`） | 结构性问题 | 它管的是「有没有讲过 / 引用能不能找到 / 组件超限」——**术语拼写不一致不在它的判据里** |

**一句话**：错在 **ASR**，但要修在**术语层**（现在术语库只会「学」，不会「治」）。

## 4. 修法建议（按代价从低到高）

1. **翻译 prompt 里加一份「本课易错听写对照」**（推荐先做）
   - 术语库已经知道**正确写法**（`molar mass`），只要再存一份**易错变体 → 正确写法**
     （`volume mass → molar mass`、`RLM → RNN`、`CLM → CNN`、`ORIN coder → autoencoder`）。
   - 变体从哪来？**自动**：同一节课里同一个位置出现两种拼法（ASR 前后不一致）→ 频次少的那一版就是变体。
     本节就有现成信号：19:8、10:3、4:2、2:4 —— 比例明显偏斜的多数派是「对」还是「错」要用**术语库**判：
     术语库里有 `molar mass`（多数派是 `volume mass`）→ 少数派 `molar mass` 才是「对」的那版？
     ⚠️ 反过来：**多数派是错的**（volume mass 19 > molar mass 8）。所以判据不能靠频次，
     要靠**术语库里已有 / 标准理论里存在的形式**（molar mass 已在术语库）。
   - 只改**译文**用词，不改 EN 原文 → 不违反「EN 是基准防倒退」那条。
2. **笔记层的术语一致性检查（确定性、可代码核）**
   - 同一篇里同一概念出现两种中文写法（体积质量 / 摩尔质量）→ 以**术语表那节**为准（它已经指向了正确形式 + 出处时间）。
   - 这类是**代码能判**的（术语表 ↔ 正文交叉），比让 LLM 自查可靠。
3. **ASR 之后的 EN 侧归一**（最有价值，但要动 EN —— **需 Owen 拍板**）
   - 把「易错变体 → 正确写法」应用到 EN 原文上，转录证据层也变干净。
   - 代价：与「EN 是基准防倒退」那条规矩冲突（那条的用意是**不让中文改写英文**；这里是**修识别错字**，性质不同，但要写清楚）。
