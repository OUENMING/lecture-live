## 2. ✅（3.9.6 已做）悬浮窗顶栏按钮：鼠标离开就淡出（hover-reveal）

- 鼠标进悬浮窗 → 顶栏按钮淡入；离开 → 淡出。时长用 `motion.STATE_S` / `EXIT_S`，减弱动态效果 = 瞬切。
- **不跟着藏**：「在听」小点（它是状态，不是控件）、字幕本身。
- 键盘 / 菜单栏入口不变（「隐藏字幕」「保持在最前」在菜单栏里）。
- 判据：行为断言「进 → alpha 1、出 → alpha 0、在听点始终可见」，并做变异验证。
