现在 Worker 只能**被动**数代理过的请求，看不到「课上得顺不顺」。下课收尾时报一次（测试模式的上传是另一回事，不动）：

- **只报数字**：上课分钟、段数、定稿走哪条路的次数（云端成功 / 退本地 / 熔断）、云端转写 p50 / p95、中文首字 p50、
