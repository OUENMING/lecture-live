## 3. ⭐ UI 评估：按钮 还是 勾选框

### 3.1 结论

**按钮（无边框 `NSButton`，两态文案）。且它不该放在顶栏。**

### 3.2 为什么不是勾选框

| 理由 | 出处 |
|---|---|
| ⚠️ **HIG 自己说系统控件与 HUD 不搭** —— 逐字：「use a HUD only ... **When you don't need to include controls** — with the exception of the disclosure triangle, **most system-provided controls don't match a HUD's appearance**」 | 本仓 `docs/RESEARCH-macos-aesthetic.md §0` **引的是一手 HIG**。而**勾选框正是** system-provided control |
| **面板上所有元素都是无边框的** —— 顶栏 🌐/❓/字幕/双语/✕、卡片上每个可点的、就绪条，**清一色无边框 `NSButton`**。勾选框自带 bezel + 焦点环 + 系统蓝 | `make_ready_strip` / `entry_panel._make_card` 的既有做法 |
| **全仓零先例** —— `setState_` 只出现过一次，是 `NSVisualEffectStateActive`（材质），与控件无关 | 现查 |
| ⚠️ **会多一条 HIG 偏离** —— 美学文档 §0 已经在数「我们违反了 HIG Panels 几条」并逐条写明理由。再加一条要有更好的理由，而这里没有 | 同上 |

### 3.3 为什么按钮够用（它要表达的是"持久状态"）

⚠️ 反对意见会是：**按钮 = 动作，勾选框 = 状态**。但**本仓已经有解**：

> 🌐 三档切换用的是**单按钮循环**，理由写在代码里：**「单按钮循环而不是两个独立开关：顶栏宽度不增，且三态互斥本就是一个枚举」**

→ **"用按钮表达一个持久状态"在这个仓库里是既成做法**，照它就行。
测试模式是**两态**（关 / 开），比三档还简单：`🎙 测试模式：关` ⇄ `🎙 测试模式：开`。

### 3.4 ⚠️ 放哪：**不放顶栏**

| | |
|---|---|
| ❌ **顶栏** | 上课时手边够得到 → **最容易误开**。而它一开就**录音**。⭐ 还有一个客观约束：顶栏刚为了宽度删掉「↓ 最新」 |
| ✅ **开课前的课程卡片面板** | 那里正是「**这节课怎么上**」的决策点；而且 D9 的社交同意**也发生在开课前** —— 两件事在时间上对齐 |

### 3.5 文案（⚠️ 用户可见，**先给作者过目**）

```
🎙  测试模式：关        ← 默认
🎙  测试模式：开 · 留音频
```

旁边一行小字（`alpha 0.65` / 11pt，与既有小字同级）：

```
开 = 这节留 Opus 音频（约 9 MB）+ 课后自动传指标
```

⚠️ **不要写成"开关"图标**（没有 switch 先例），也**不要加系统勾选框**（§3.2）。

### 3.6 判据

照 `tests/test_panel.py` 的宽度扫描：**新控件不压到任何可见按钮** · 文案随状态变 · 点击真的触发回调（**钉行为，不钉 flag** —— 本仓 `ClickView` 就是 `flag=True` 且完全正常）。

## 5. 录音：Opus 分段

### 5.1 实测（两段真课堂录音，16k 单声道）

| 格式 | 占 PCM | 1 节课(50min) | 1 天 3 节 | 1 学期 |
|---|---|---|---|---|
| **现在：wav 16/16** | 100% | **97 MB** | 291 MB | 17 GB |
| FLAC（无损） | 66–71% | 69 MB | 207 MB | 12 GB |
| **Opus 24k** | **9.0%** | **9 MB** | **27 MB** | **1.6 GB** |
| Opus 16k | 6.0% | 6 MB | 18 MB | 1.1 GB |

→ **选 Opus 24k**。⚠️ FLAC 只省 30%，**不值**。

### 5.2 ⚠️ 一个必须写进注释的诚实前提

「Opus 24k 对 ASR 无损」的依据：NoLACE(Amazon 2024) LibriSpeech clean 2.01% → Opus 20k **2.03%**；
Khare 2020：16k **+12.6%** / 32k +6.6% WER 退化。
⚠️ **但这些全是朗读或远场数据，没有一条是教室噪声录音**，也没找到 Whisper×Opus 的一手评测。
→ **24–32k 起步、不要低于 16**；这条是**外推**，不是实测背书。

### 5.3 怎么录

- 复用 `testmode.TestSession` 已有的 wav 写盘路径，**改成：每 10 分钟切一个文件**
- ⚠️ **切点按 `n_samples` 整除，不按墙钟** —— 否则段间会丢样本

#### ⚠️⚠️ ffmpeg：**它已经是本仓的外部依赖，不是新引的**

初稿我写成「仓库没有 ffmpeg」—— **错的**，现查更正：

- `capture.load_file()` **已经在用它**（`subprocess.run(["ffmpeg", ...])`，给 `--source file` 解码任意格式）
- `cl` 与 `update._child_env()` 各自**补过 PATH**：`.app` 双击启动时 PATH 只剩
  `/usr/bin:/bin:/usr/sbin:/sbin`，而 ffmpeg 在 `/opt/homebrew/bin` —— **仓库已经踩过并修过**
- 它**不在 `requirements.txt` 里**（那是 pip 清单，ffmpeg 是二进制）

→ **所以要定的不是「引不引」，而是「在哪一步调它」**：

| 方案 | 上课路径 | 磁盘峰值 | 判断 |
|---|---|---|---|
| **(a) 边录边编码**（ffmpeg 常驻，喂 stdin） | ⚠️ **多一个长跑子进程** | 9 MB | ❌ |
| **(b) 录 wav → 收尾一次性转 Opus → 删 wav** | ✅ **零新增** | 97 MB/节 | ✅ **选它** |

⭐ 理由是仓库自己那条纪律：**「绝不能影响上课」**（`testmode.py` 文件头第 1 条）。
(b) 把转码整个挪到**收尾**，上课路径一个字节都不动。
⚠️ 但它要**多占 ~97 MB 磁盘**（一节课的原始 wav）—— 收尾转完就删。
⚠️ PATH：照 `capture.load_file` 的形状调，**别自己拼绝对路径**。
   ✅ **已核实不是缺口**：`entry_launch.py` 自己那段注释写着链路是
   **双击 `.app` → `cl`（零参数分支）→ `entry_launch` → `cl` → `main.py`** ——
   **PATH 是 `cl` 补的**（`cl:37-44`），下游全继承。`entry_launch` 不用自己补。

## 6. 上传：队列与策略

### 6.1 形状（照调研的成熟做法）

```
收尾 → 写 pending 队列（落盘，不在内存）
         ↓
  下次启动 / 课后空闲 → 后台线程
         ↓
  分批 flush（每分钟最多一批）
         ↓
  失败 → 指数退避 1 min → 上限 120 min
         ↓
  超过 14 天 → 丢弃（Firefox 的参数模板）
```

### 6.2 五条要点

| 要点 | 怎么做 | 出处 |
|---|---|---|
| **落盘用 tmp→rename** | 半截文件**不进队列** | Glean（一手） |
| **幂等** | key = **内容哈希**（`sha256`）。⚠️ **顺带解决元数据泄漏** —— 原文件名含**课号 + 精确时间戳** = 一份课表 | Glean 形状 + Homebrew 的「故意粗化元数据」范式 |
| **计费网络** | ⚠️ **别自己判** —— Apple 明说用 `allowsExpensiveNetworkAccess=false` + `waitsForConnectivity=true`，**让系统等到合适网络** | Apple 一手 |
| **逐文件失败分开** | 一节课挂了不拖住其余 | Sentry 一手 |
| **开关关掉 = 连队列一起删** | 隐私工具的额外一条 | Glean 的 `deletion_request` 旁路 |

### 6.3 传什么

| | 大小 | 授权 |
|---|---|---|
| `report.json` + `env.json` + `session.md` | 5–20 KB | ✅ 静默自动传 |
| `audio/*.opus` | 9 MB/节 | ✅ 传（D6），但**界面要有可见的录音指示** |

### 6.4 落点

- 作者手上的工具：`rsync` / `scp` / **`aws` CLI**（R2 是 S3 兼容 → `aws s3 --endpoint-url`）
- 服务端：**生命周期规则 90 天**（D8）· **留「会话 → 对象」索引**（§2 的"要能删"）
