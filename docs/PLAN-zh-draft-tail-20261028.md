# PLAN：中文草稿只译尾巴（长草稿不再冻在开头）

2026-10-28 · 状态：**Z1 已实现（未提交，未发版）**；A 显示层上移另开方案 · 备份：`~/Desktop/classlive-review/backup-20261028-zhdraft/`（HEAD=`f712733`，工作区干净）

## 1. 问题（实测）

美国用户 10-27 ECS170（`98643a73`，3.10.3）第 40 分钟起 Soniox 不再给标点：

| 量 | 实测 | 来源 |
|---|---|---|
| 空洞内英文草稿长度 | 178 → 3432 字 | `live.jsonl` draft |
| 空洞内中文草稿长度 | 恒 ≈ 225–237 字（max 237，p99 234） | `live.jsonl` draft_zh |
| 空洞内中文变体数 | 78 次更新 / 75 种不同文本，**全是开头那一段的不同译法** | 同上 |
| 全课英文草稿 >90 词累计 | 606 s（>60 词 780 s，>120 词 460 s） | 同上 |

机制（代码已核）：
1. 无标点 → `sealed_prefix()` 恒为空（`draft_translate.py:26`）→ `_step_locked` 走"整段重译"（`draft_translate.py` 末段 `self._translate(text, …)`）。
2. 整段英文送 `translate_draft`，输出被 `max_tokens=120` 截断（`cloud_translator.py:547`）≈ 230 汉字 ≈ 英文开头约 150 词。
3. 之后英文再长，译文**永远只含开头**；每次重译措辞略变 → 抖动。屏幕上中文是几分钟前那句，不是老师现在说的。
4. 副作用：每次送翻的输入随草稿线性变长（空洞末期 ~3.4k 字符 / 次），白花 token。

健康课不触发：标点正常 → 封口前缀锁住，只译短尾巴。所以 10-27 之前没人发现。

## 2. 方案对比

| 档 | 做法 | 优点 | 代价 / 风险 |
|---|---|---|---|
| **Z1（推荐）** | 整段重译路径与 `rest` 路径，英文送翻前**裁成最后 K 词**（K=40，按词边界） | 中文永远对应"老师现在说的"；输入有上界 → 省钱、降首字延迟；改动 ≈ 一个纯函数 + 两处调用 | 草稿期中文只显示最近 ~40 词的译文，开头那段不显示（定稿时会补齐，本来就是"先看版"） |
| Z2 | `max_tokens` 120 → 400 | 一行改动 | 仍整段重译，输入无上界；延迟、费用都涨；译文长了屏幕也放不下（2 行档） |
| Z3 | 无标点时按停顿/词数自造"伪封口前缀"并锁住 | 省重译 | 复杂，容易和 `continues()`/代次逻辑打架；不推荐 |

选 **Z1**。K=40 依据：2 行档宽 661 px 约容纳 60–70 汉字；40 英文词 ≈ 60–80 汉字，刚好一屏，且远低于 120 token 上限（离截断有 3× 余量）。

## 2.5 复核补充（10-28 写测试前）

- 跨会话：健康课（Owen 10-20/10-23，3 节）英文草稿最长 42–70 词、**没有一次 >90 词**；中文草稿 max 52/224/121。只有 10-27 这节撞上 237 字的硬顶 → 症状是这类故障独有的。
- 对健康课的影响：未封口部分 >40 词的草稿占比 549c 0.0% / 474ac8 1.5% / 16c610 2.0%（10-27 那节 26.3%）。K=40 平时几乎碰不到；碰到时屏幕本来也只放得下译文开头 2 行（尾部被「…」截掉），裁成尾巴只会让可见部分更接近此刻。
- 补充设计：窗口起点按 TAIL_STEP=8 跳（窗口 33–40 词），避免每多一词中文开头就换措辞。
- 裁剪范围：只裁**未封口**的（整段重译 / lock 之后的 rest / 封口后的尾巴）；封口句整句译整句锁，不裁。
- 已知边界：封口前缀本身若 >150 词（标点极稀疏）仍会被 120 token 截；本方案不处理。

## 3. 具体改动（Z1）

1. `draft_translate.py` 新增纯函数 `clip_tail(text, max_words=40) -> str`：
   - 词数 ≤ K 原样返回；
   - 否则取最后 K 词；若前 3 词内有句末/逗号标点，往后挪到该标点后（尽量从子句起头）；
   - 不改大小写、不补标点。
2. `DraftTranslator._step_locked`：
   - 走 `self._translate(text, …)`（无锁住前缀）处：改传 `clip_tail(text)`；
   - 走 `rest` 处：`rest` 同样 `clip_tail`；
   - `zh = lk["zh"]` 拼接逻辑不动（锁住的封口中文在前，尾巴在后）。
3. 不改：`sealed_prefix`、`continues`、`DraftView`、`draft_policy`、`cloud_translator.max_tokens`（保留 120 当兜底）。
4. 同步 `live.jsonl`：`draft_zh` 事件加一个 `clipped: true`（仅被裁时）→ 以后复盘能直接数"多少秒在裁"。**可选**，不加也不影响功能。
