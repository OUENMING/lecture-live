改前 / 改后的真实代码

  • 改前 DraftView.on_draft()：只有 seg > cur_seg 才可能清中文；同 seg 的下一句直接返回 false，旧中文留在 _draft_zh_val。
  • 改后 DraftView.on_draft()：同 seg 但文本不再接着长（continues() 为假）也清；并给句子代次 +1，上一代的晚到译文由 accept() 丢掉。
  • 改后 caption_flow：MIN_WORDS=1，首词就占新行；TAIL_WORDS=3 + TAIL_STARTERS 把 Okay?/So 这类口头禅并进上一行。
  • HOLD_MAX_S=2.5：上一句定稿还在流式时，下一句草稿最多被挡 2.5 秒（保留）。

调研结论（先看方向）

  • BBC Subtitle Guidelines：live subtitles 应 word by word、左到右出现；一句一个字幕，尽量在标点/句末换行，使用两行滚动。支持首词切行
  • CHI 2023 · Text Stability in Live Captions：实时字幕的抖动会显著增加分心/疲劳；应保留已显示行的换行、不要重排旧行，用平滑动画。旧行冻结
  • Netflix Timed Text Style Guide：换行在标点后/连词前，避免把名词和冠词拆开；最多两行。句边界换行
  • 结论：新句首词切行方向正确，但“Okay?”这类口头禅要并进上一行，不能每句都无条件新行。
