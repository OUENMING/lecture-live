# 转录→笔记正确率：怎样才真的提升（2026-11-21，第二轮）

问题：做了很多轮「让模型自查 / 加规则 / 加正则」，正确率没明显变。为什么，下一步押哪里。
方法：research-sop 两轮（论文 + 评测媒体 + 社区）＋ 对照我们自己的 17 条金标错误（`tests/fixtures/local_runs/gold_errors.json`）。抓取日期 2026-11-21。

## 1. 我们的错到底是哪一类（17 条金标，手分类）

| 类 | 条数 | 例子 | 谁能抓 |
|---|---|---|---|
| 推导/算术/符号错 | 8 | ECS170 梯度正负号×3、阶跃函数 ×2、矩阵行列；ECON10790 漏根 q=6；DWL 底高 | **代码**能抓（重算、代入） |
| 语义改写（关系、对象、程度被换） | 6 | 「至少一个参数≠0」→「不显著」；Kiera 讲师→导师；「差距在改善」→「女生多于男生」；总收益 15→50 | 只能靠**原话对照**（时间戳 + 引文） |
| 源头就错（ASR/老师口误） | 3 | 92−6Q 听成 92−62；「比工资多 660」实为多 90；口播 2,314 | 课件/题面对照；或标「原话存疑」 |

结论：**大头（14/17）是模型自己写错，不是转录错**。所以「提高 ASR」「再让模型读一遍」都打不到要害。

## 3. 和我们历史对上

- 过去「没效果」的几轮，基本都是**同一个模型再读一遍**（verify / repair / 自查提示）——正对应第 2 节第 1 条。
- 过去**有效**的两次都是外部反馈：链式重算 7→22 处核对；种错误检测 18%→34%（见记忆卡，旧值，未重测）。
- 所以：继续加「请仔细核对」类提示词，预期仍无效。

## 4. 建议（按预期收益排）

1. **缩小不可核的生成面**：结构计划（本轮 W1）让每节只写分给它的内容，少写「总结、类比、延伸」这类最容易改写原意的话。
2. **关系类断言强制带原话**：每条「X 是 Y / X 导致 Y / 至少一个…」写进正文前要带 `[时间戳]` + 原话片段；渲染时可点开对照。代码检查：引文必须逐字出现在转录里，找不到就降级为「待你确认」。这是唯一能打到「语义改写」6 条的办法。
3. **算式全部走代码重算**（已有 note_math，扩到符号/正负号/矩阵）：打 8 条推导错。
4. **课件当标准**：有课件时，数字和定义先对课件（📖 > 🎙）；打「源头错」3 条。
5. **模型档位**：effort high 只在实验臂测（产品保持 low，Owen 定的）。没有测量前不下结论。

## 7. 第三轮实现与实测（2026-11-22 凌晨，新版 low + 三项改动，5 节课各 1 次）

改动：① `note_ground.py`（开关 `CLASSLIVE_NOTE_GROUND`，默认 0）未核对的讲解断言 → 代码找转录原话（数字/英文词 + 前后各一行）→ 1 次调用判支持；只许 未核→已核，永不出 mismatch；引文必须真在原话里。② `merge_units` 把成员标题的子题留成 `## 子题`，HTML 渲染成 h4、导图二级改用小标题。③ `note_guards.corner_quotes`：中文语境直引号 → 「」，纯英文原话 → “”（quote_check 仍认得）。
