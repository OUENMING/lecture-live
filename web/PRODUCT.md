## Platform

web

## Users
- 第一批：拿到通行码的朋友 —— 在英语授课的大学（都柏林等）上课的中文母语学生，课上需要实时双语字幕、课后要笔记。点朋友发来的链接进来，通常是快上课了。
- 以后：会在小红书等公开分享（Owen 2026-11-17 确认），门面要能单独打动陌生人；但使用仍凭通行码。

## Product Purpose
ClassLive 网页版是桌面版的免安装入门版：打开网址 → 允许麦克风 → 输一次通行码 → 实时双语字幕（含课程术语注入）→ 下课后笔记出现在同一页面。成功 = 第一次来的人不看说明、在开课前一分钟内就能出字幕。

## Positioning
- 实时英译中课堂字幕，按课程术语表注入识别端和翻译端（课件上传生成术语表）；字幕边说边出、整句定稿，课后自动出结构化笔记。
- 作者本人每天用桌面版上真课，网页版复用同一份 Python 实时核心（Pyodide 跑，与桌面逐字节相同）。

## Operating Context
- 教室里笔记本放桌上，旁边开着课件 / Zoom；字幕常驻在置顶小窗（Document PiP）浮在课件上。
- Zoom 全屏会议（macOS 原生全屏 Space）里小窗浮不上去 → 引导用桌面版。
- 只承诺桌面 Chrome / Edge（Mac 与 Windows）；其他浏览器在开课前说明。

## Capabilities and Constraints
- 第一版：麦克风实时转录 · 逐句翻译 · 术语注入 · 逐句落盘不丢 · 置顶字幕小窗 · 课件 → 术语表 · 下课出笔记（页面内看、下载 md / html）。
- 后续：网课音源（抓标签页 / 系统声）· 实时总结 · ❓ 标记 · 讲解问答 · 手机 · Safari / Firefox。
- 不上传音频；服务器存逐字稿 / 笔记 / 术语表 30 天，可立即删除。
- 没有本地模型 / 离线模式（要离线用桌面版）。

## Brand Commitments
- 名字：ClassLive。
- 上课界面与桌面版同一套：深色磨砂底 + 白字，**不用彩色强调**（Owen 2026-11-17：去掉琥珀色，只用白）；中文主 / 英文副，英文在上。
- 门面（开课页）白底；从门面到上课是一次由亮到暗的原地过渡（约 350 ms，其余动效 ≤ 200 ms）。
- 上课默认深色；可切亮色。
- 基调：高级感、优雅、克制，但功能不能少（Owen 2026-11-14）。

## Evidence on Hand
- 真课字幕回放（作者自己的课）：`~/classlive-web-spike/s3/app/static/data/replay.json` —— 只在本机，公开页面上用要先换成可公开的片段或明确标「示例」。
- S1–S4 穿刺实测数字（WER、延迟、长任务）：`~/classlive-web-spike/`。
- 没有用户评价、没有用户数、没有媒体报道 —— 不许编。

## Product Principles
1. 快上课了的人只要一件事：马上出字幕。每多一步都要有理由。
2. 失败必须看得见（降级 / 断线 / 没声音都上屏），不许静默。
3. 字幕可读压倒一切装饰：浮在任何课件上都看得清。
4. 说清楚存了什么、存多久、怎么删。

## Accessibility & Inclusion
- 尊重 `prefers-reduced-motion`：过渡退成淡入。
- 中文为主界面语言；字幕字号可缩放。
